Linux installation and troubleshooting

RBC Community Map is tested on Linux Mint Cinnamon. The application uses PySide6 and Qt WebEngine for the embedded browser, and uses the desktop Secret Service through keyring for saved passwords and session cookies.

Install the system packages

Linux Mint 22.x and Ubuntu 24.04 do not provide the required PySide6 + Qt WebEngine modules as native packages. Install the runtime libraries below, then install the pinned Python wheels in a virtual environment:

sudo apt update
sudo apt install -y python3 python3-pip python3-venv \
  ca-certificates libsqlite3-0 libssl3t64 libglib2.0-0t64 \
  libdbus-1-3 libfontconfig1 libfreetype6 libpng16-16t64 libexpat1 \
  libegl1 libgl1 libglx0 libglvnd0 libgbm1 libdrm2 libgl1-mesa-dri \
  libxkbcommon0 libxkbcommon-x11-0 libxkbfile1 libx11-6 libx11-xcb1 \
  libxau6 libxdmcp6 libxcb1 libxcb-cursor0 libxcb-icccm4 \
  libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render0 \
  libxcb-render-util0 libxcb-shape0 libxcb-shm0 libxcb-sync1 \
  libxcb-util1 libxcb-xfixes0 libxcb-xkb1 libxcb-dri3-0 libxcb-glx0 \
  libxcomposite1 libxdamage1 libxext6 libxfixes3 libxrandr2 \
  libxrender1 libxtst6 libnss3 libnspr4 libasound2t64 \
  libgssapi-krb5-2 fonts-dejavu-core gnome-keyring dbus-user-session \
  libsecret-1-0 xdg-utils

On pre-24.04 Ubuntu-based releases, use libssl3, libglib2.0-0, libpng16-16, and libasound2 when the *t64 names are not available.

seahorse is optional but useful for confirming that the login keyring is unlocked and that RBC Community Map entries were saved.

Native package alternatives

On Debian 13 or Ubuntu 25.04 and later, the distribution may provide native PySide6 WebEngine packages:

sudo apt install python3 python3-pyside6.qtcore python3-pyside6.qtgui \
  python3-pyside6.qtwidgets python3-pyside6.qtnetwork \
  python3-pyside6.qtwebchannel python3-pyside6.qtwebenginecore \
  python3-pyside6.qtwebenginewidgets python3-bs4 python3-requests \
  python3-keyring python3-secretstorage python3-jeepney \
  gnome-keyring xdg-utils

Fedora/RHEL 8+ uses dnf; on those systems yum is an alias. RHEL, Rocky, and Alma may need EPEL for some packages:

sudo dnf install python3 python3-pip xcb-util-cursor xcb-util-wm \
  xcb-util-image xcb-util-keysyms xcb-util-renderutil libxkbcommon-x11 \
  nss alsa-lib mesa-libEGL mesa-libgbm gnome-keyring libsecret \
  dbus-daemon xdg-utils

Arch/Manjaro uses:

sudo pacman -S --needed python python-pip xcb-util-cursor xcb-util-wm \
  xcb-util-image xcb-util-keysyms xcb-util-renderutil libxkbcommon-x11 \
  nss alsa-lib mesa gnome-keyring libsecret xdg-utils

If a distribution lacks a package, use the corresponding PyPI dependency in the virtual environment and install the matching system-library equivalent.

Create an isolated Python environment

python3 -m venv ~/.venvs/rbc-map
~/.venvs/rbc-map/bin/python -m pip install --upgrade pip
~/.venvs/rbc-map/bin/python -m pip install -r requirements.txt
~/.venvs/rbc-map/bin/python main_1.0.4.py

Using a virtual environment avoids conflicts with a distribution-managed Python. If the distribution blocks system-wide pip installation, do not remove that protection; use the virtual environment instead. --break-system-packages is appropriate only for a disposable test machine.

Package-name alternatives

  • On newer Ubuntu-based releases, libasound2 may be named libasound2t64; install whichever name apt-cache policy reports.
  • If libxcb-cursor0 is unavailable, refresh the distribution repositories and confirm that the normal Ubuntu/Mint repository components are enabled. This library is required by the Qt xcb platform plugin; substituting an unrelated xcb package will not fix that error.
  • Package names differ on Fedora, Arch, and other distributions. Use the distribution's Qt6 WebEngine, XCB, OpenGL/EGL, NSS, ALSA, D-Bus, GNOME Keyring, and libsecret package equivalents, then install the Python dependencies from requirements.txt in a virtual environment.

Keyring setup

Before the first run, log into a desktop session with D-Bus available and unlock the login keyring. If the keyring is missing or locked, install and start the distribution's GNOME Keyring/Secret Service provider. On KDE, KWallet (5.97+/6) can provide the Secret Service path; the app respects a KWallet-first chained backend. Use Seahorse to unlock or inspect the store, then restart RBC Community Map. A locked or unresponsive keyring is detected and saved-credential operations are stopped rather than left waiting indefinitely.

The first successful migration removes secret values from the active SQLite rows only after writing and reading them back from the operating-system credential store. Do not treat the database as protected until migration succeeds.

Credential-store fallback

Warning: the SQLite profile stores saved passwords and session cookies in plaintext. Use it only when the OS credential store cannot be made available, and do not share or commit its data directory.
source ~/.venvs/rbc-map/bin/activate
RBC_MAP_CREDENTIAL_STORAGE=sqlite python main_1.0.4.py

This uses a separate RBC-Map-SQLite data directory. Add the characters again in that profile. Remove the environment variable to return to the normal keyring-backed profile.

Virtual machines and software rendering

For virtual machines with incomplete GPU support, the application configures Chromium and Qt for software rendering. If the window is blank or fails to start, confirm the X11/Qt packages above are installed and launch from a desktop session rather than a bare TTY. The application log is the best place to distinguish a Qt platform-plugin error from a keyring error.

Quick verification

~/.venvs/rbc-map/bin/python -c "import PySide6, keyring; print(PySide6.__version__); print(keyring.get_keyring())"
~/.venvs/rbc-map/bin/python -m py_compile main_1.0.4.py
~/.venvs/rbc-map/bin/python tools/check_credential_store.py

Run the checks from a source checkout. A working Mint setup normally reports a chained keyring containing Secret Service/libsecret backends. The credential-store checker uses fakes and does not replace a live GUI sign-in test.
